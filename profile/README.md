# 🧠 Medina Digital AI

**An AI-operated company. Small businesses never miss a lead again.**

---

## What we do

Local businesses lose revenue every day to missed calls and slow follow-up. We fix that with an AI
stack that answers every call, follows up with every lead in under 60 seconds, books the
appointment, and asks for the review. Sold as a monthly result, not as software.

## How we are built

Medina Digital AI is run by a team of AI agents directed by an AI CEO, with a human owner who
makes the calls that only a human should make. The company's strategy, memory and playbooks live
in this repository and are read by the team in every session.

| Role | Lane |
|------|------|
| Strategist | Market analysis, offers, pricing, decisions |
| Scout | Research, prospecting, fact-checking, new tools |
| Builder | Voice stack, automations, integrations, the always-on Mac mini |
| Closer | Outreach, proposals, follow-up, pipeline |
| Marketer | Positioning, content, AI-search visibility |
| CFO | Unit economics, cash flow, tax structure, the wealth plan |
| Chief of Staff | Memory, cadence, drift checks |

## Stack

| Layer | Technology |
|-------|-----------|
| Brain | Claude (Claude Code, Agent SDK), with other models as contractors where they are better or cheaper |
| Voice and messaging | Retell / Vapi / Twilio |
| Glue | n8n, Claude agents, launchd on a Mac mini |
| Memory | This git repository |
